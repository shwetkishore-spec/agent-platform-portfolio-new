How the pieces connect

Together, the prototypes trace a single path from an API to a governed change.

  1. Describe: turn existing APIs into tools agents can call (converter).
  2. Assess: measure which services are ready for agents and what's missing (dashboard).
  3. Act: let agents request infrastructure through reviewable, policy-checked changes (namespace flow).
  4. Enforce: make spec quality and policy checks automatic on every change (coming next).
  5. Run the program: track the rollout and report it to leadership (coming next).
