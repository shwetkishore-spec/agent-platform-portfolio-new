How the mapping works: each path + method becomes one tool. The name comes from operationId (or is built from the method and path). Path and query parameters and JSON request-body fields become the tool's inputSchema. GET is marked read-only, PUT idempotent, and DELETE destructive, using MCP tool annotations. The output matches the shape of an MCP tools/list result. Everything runs in your browser; nothing is uploaded.
